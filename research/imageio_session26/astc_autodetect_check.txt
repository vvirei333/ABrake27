# ASTC Autodetect Registration Verification
# Session 30 — 2026-10-06

## IIO_ReaderHandler::buildPluginList — xref confirmed call chain:

  buildPluginList() calls ALL CreateReader_* factories to populate
  the format-sniffing registry. Each factory returns an IIO_Reader
  subclass with testHeader() and createReadPlugin() implementations.

  When a client calls CGImageSourceCreateImageAtIndex:
    1. ImageIO iterates the plugin list
    2. Each reader's testHeader() is called against the file header
    3. First match wins → createReadPlugin() instantiates the decoder
    4. Reader::initialize() parses the format-specific header
       ← THIS is where ASTCReadPlugin::initialize runs
       ← THIS is where the hardened bounds checks were added in beta

## Xref evidence:
  CreateReader_ASTC     → buildPluginList+776    (both stable & beta)
  CreateReader_DDS_ASTC → buildPluginList+2104   (beta ONLY — new format)

## _IIO_ReaderSelection data:
